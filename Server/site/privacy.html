隐私说明

2026 年 11 月 27 日

番外没有账号，不需要注册，不放广告，也没有接入任何统计或追踪工具。下面写的是它在什么时候会把什么发到哪里。

留在手机上的

  • 你的收藏、稍后听、浏览和搜索记录，以及查到过的卡片和故事。
  • 你填的模型 API Key 和体验码，存在系统钥匙串里。

这些资料默认留在手机上。只有你主动提交下面的「结果反馈」时，当前页面的那份结果会随反馈发送；不会上传整份收藏或浏览记录。删掉 App，收藏和记录就一起删掉了；「设置」里也可以单独清除浏览记录。钥匙串里的 API Key 由系统保管，删 App 后可能还留着，想清掉可以先在「设置」的「模型」页点「移除密钥」。

查一首歌时发出去的

  • Apple。番外读取 Apple Music 正在播放的歌，并用歌名和歌手到 Apple 的曲库里找对应的版本。读取正在播放需要你在系统弹窗里同意。
  • 公开资料库。歌名、歌手、专辑和作品名会发给 Wikidata、维基百科、MusicBrainz、Bangumi、豆瓣这类公开网站，用来找相关作品和封面。用 QQ 音乐或网易云音乐时，你粘贴的链接和搜索的歌名会发给对应的平台。
  • 你选的模型服务。歌名、歌手、专辑，以及搜索到的网页内容，会发给你在「设置」里选的服务商（比如 DeepSeek 或 OpenAI），由它联网搜索并写出故事。请求用你自己的 API Key，直接从手机发到服务商，不经过番外的服务器。服务商怎么处理这些内容，以它自己的隐私政策为准。

用体验码时

体验码是朋友之间发的免费额度。用体验码查歌时，上面发给模型服务的内容会先经过番外设在香港的服务器，再转给 DeepSeek，费用由番外承担。

这台服务器会记下：哪个体验码、查了哪首歌（歌名和歌手）、调用了几次、花了多少钱、有没有查到故事。用途只有两个：算花费，以及出问题时排查。记录保留 90 天，不给别人，不用来做别的，里面也不存你的 IP 地址。

不用体验码、填自己的 API Key 时，查歌请求不经过番外的服务器。你主动提交的结果反馈单独按下节处理。

主动提交结果反馈时

在页面右上「更多」里点「反馈」，再点「提交反馈」，会向番外在香港的服务器发送：你选的问题和补充文字、打开弹窗时的歌曲或作品、当前故事、关联卡片及其公开来源、查找状态，以及 App／系统版本和该作品的有限诊断信息。这些用于逐条定位和修复问题，收到后保留 90 天，不提供给第三方。

不会自动截屏，不附带 API Key、体验码、登录凭证、整份资料库或模型请求原文。常见密钥和TestFlight 反馈格式会在发送和接收时隐去，请不要在补充文字里填写私人资料。App 会生成只用于反馈去重的随机安装编号；服务器保存其摘要，不关联 Apple 账号。IP 摘要仅在内存中用于一小时限频，不写入反馈记录。

断网时反馈先保存在手机，联网或回到 App 后补发；只有服务器确认保存才显示「已收到」。反馈不会触发重新查歌或扣除体验次数。若想删除已提交的反馈，可通过 TestFlight 的「共享 Beta 版反馈」联系作者，并说明作品和提交时间。

App 启动时

番外会向 fanwai.xyz 读取一份公开的配置，比如默认的模型名、免费体验现在开没开。这个请求不带任何关于你的信息。

TestFlight

内测版通过 Apple 的 TestFlight 分发。崩溃记录和你主动提交的反馈（截屏和文字）由 Apple 收集后转给开发者，规则见 Apple 的 TestFlight 条款。

这个网站

公开介绍、隐私和使用说明是静态网页，不放 Cookie，不加载第三方脚本，不保存访问日志。开发者管理区另有登录 Cookie，仅用于管理身份验证，不用于追踪访客。

联系

关于隐私的问题或记录删除请求，请通过 TestFlight 的「共享 Beta 版反馈」联系作者。

有变化时

这份说明改动时，会更新上面的日期。
