使用和反馈

内测阶段

故事那里是空的

没找到有出处的内容时，番外不编。冷门的歌、纯器乐的原声曲常常只有卡片，没有故事。页面上有「深挖」时可以多查一轮，会多花一点模型费用。

提示余额不足，或者 API Key 用不了

到你用的模型服务的后台看一下余额和这把 Key 还在不在。DeepSeek 的后台是 platform.deepseek.com。改好后回到番外，点页面上的「重查」。

用 QQ 音乐或网易云音乐

这两个 App 不让别的 App 读取正在播放的歌。在歌曲页点「分享」，选「复制链接」，回到番外，顶部会出现「查刚复制的链接」，点「粘贴」。也可以直接在番外的「搜索」里搜歌名。

查出来的东西不对

支持结果反馈的新版中，在那个页面点右上「更多」→「反馈」→「提交反馈」。原因和补充都可以不填，也可以选多个问题。反馈会带上打开时的歌曲、当前故事和关联，不用另截屏；不会重新查歌或扣体验次数。

显示「已收到」表示已经保存到后台；「已保存，稍后发送」表示先留在手机，联网或回到 App 后补发。没有这个入口的旧版仍可截屏后选「共享 Beta 版反馈」。

体验码

体验码由开发者发给参加内测的朋友，一个码有固定的次数，一首歌第一次查算一次。用完后在「设置」里的「模型」页填自己的 API Key 就能继续用。

别的问题

可通过 TestFlight 的「共享 Beta 版反馈」联系作者。
